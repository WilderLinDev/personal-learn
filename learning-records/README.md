# Learning Records

Learning records are the durable history of the learner's progress. They are historical snapshots, not the canonical source for current factual explanations.

Name files NNNN-<slug>.md, incrementing the number for each substantive learning session. Preserve earlier records. Capture what the learner studied, what they can explain or apply, misconceptions and difficult areas, open questions, related knowledge and sources, mastery changes, and next review.

Detailed learning history and progress are intentionally part of this public project.
