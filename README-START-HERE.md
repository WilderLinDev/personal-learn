# Start Here

1. Read README.md and MISSION.md.
2. If using ChatGPT, create a Project named Personal Learning.
3. Copy docs/CHATGPT-PROJECT-INSTRUCTIONS.md into Project Instructions.
4. Enable the GitHub connection and make sure this repository is accessible.
5. Start a new conversation in that Project and ask to learn a topic.

The Project instructions are a bootstrap. The GitHub repository remains the source of truth. For other AI agents, follow docs/COMPATIBILITY.md.
